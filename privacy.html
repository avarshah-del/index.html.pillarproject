Privacy

The Pillar Project does not sell personal information, and it does not share it with advertisers. Agent progress stays in the visitor's own browser. A few features, described below, can send a question, an email sign-up, or a nickname off the device. Nothing else is collected for a profile.

What is stored

The Agent Training Zone keeps progress only in localStorage on that browser. There is no account and no password. On each visit, the Training Zone deletes any old password it finds: the password field inside hq_users, and any localStorage key, sessionStorage key, or cookie whose name contains "password".

hq_users

One record for each first name or nickname typed on this browser. The name is the key. Each record can hold:

  • avatarLayers — the avatar pictures that were picked
  • xp — points
  • zones — which of the four brain zones are finished
  • brainBitsClaimed — whether the Brain Bits watch bonus was claimed
  • brainBitsQuiz — which Amygdala quiz questions were answered
  • doodleClaimed — whether the doodle-sheet bonus was claimed
  • defenseClaimed — whether the Defense Simulator bonus was claimed
  • level2Unlocked and masterUnlocked — clearance rewards
  • hallOfFameState — whether that nickname was sent to the Hall of Fame
  • masterUnlockedAt — the date Master Agent was redeemed

Older visits also stored a password on this record. That field is removed when the Training Zone loads. The name, points, and zone progress stay.

brain_bits_quiz_awarded

A small list of Amygdala quiz question ids that already awarded points, so the same question is not paid twice. It does not include a name.

active_hq_agent

This one is in sessionStorage, not localStorage. It is the first name or nickname of the agent signed in on this tab, so a refresh can continue. It is cleared when the tab closes, and when you sign out. It is not a password. Educator preview (?preview=1) does not write these records.

The chatbot is AI

Microglia, the chat button on these pages, and the Microglia Intel Bot on the Agent Training Zone, are not a scripted answer list. Each question is sent to an AI service at https://brain-hq-bot.avarshah.workers.dev.

Chat answers come from an open-source AI model (Meta Llama 3.1) run by Cloudflare. Cloudflare doesn't keep or train on chat messages, and we don't store them.

The message that leaves the device is:

  • userMessage — the question you typed
  • history — up to the last 6 turns of that chat. The history lives in the page's memory for the visit. It is not saved in localStorage.
  • activePage — the name of the page. On the Training Zone, that also includes which screen is open and which brain zone, if one is open.

The chat does not send the agent name, the points, or the rest of localStorage. If the connection fails, the page says so and stores nothing extra. Do not type a real full name, school, address, or email into the chat.

Parent email sign-up

The forms on Home and on Case Alzheimer's are for parents and caregivers. When a sign-up is sent, it goes to a Google Sheet owned by The Pillar Project. The sheet is used only to send updates. The fields are the name (optional), the email, the interests that were checked, the page the form was on, and a consent "yes".

Emails are sent by hand from contactpillarproject@gmail.com. There is no account. Anyone can unsubscribe by emailing that same address.

Until the sheet connection is turned on, both forms say "Sign-ups open soon" and do not send anything.

Hall of Fame

If an agent redeems Master Agent, the Training Zone sends that first name or nickname to https://hall-of-fame.avarshah.workers.dev so it can appear on the public Hall of Fame, with the date it was added. It does not send an email, an age, or a password. Preview mode does not send a name. Reading the list is a request for the names already on the board.

Kids under 13

Kids under 13 should not enter personal information. On the Training Zone, use a first name or nickname only. Do not type a full name, school, address, or email into the chatbot or the agent sign-in.

Analytics

This site does not include Cloudflare Web Analytics, Google Analytics, or another analytics script. Pages do not set a tracking cookie of their own.

The Media page loads an Elfsight script to show an Instagram feed. Some pages embed YouTube videos, which load from YouTube. Those embeds are separate from the progress stored in this browser.

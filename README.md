# The Pillar Project 💜

Welcome to the official repository for **The Pillar Project**, a Gen Z-led community initiative dedicated to bridging the gap in memory care. 

This repository hosts the source code for our single-page website, built to showcase our mission, connect with volunteers, and share resources for families navigating Alzheimer's disease.

## 🌟 Our Mission
When Alzheimer's impacts a family, primary caregivers often shoulder immense physical and emotional burnout. We mobilize high school volunteers to provide grassroots, intergenerational support. 

Through our **"Divide and Pamper"** model, we provide:
* **Sensory Engagement:** Interactive art, music, and tactile sessions for memory care patients.
* **Caregiver Respite:** Dedicated, guilt-free time for family caregivers to breathe and relax.
* **Wellness Baskets:** Curated stress-relief packages to support caregiver mental health.

## 📚 Case Alzheimers: A Brain HQ Mystery
In addition to our on-the-ground volunteer work, we are the creators of the upcoming children's book *Case Alzheimers*. The book turns memory loss into an approachable spy adventure to help parents easily explain the complexities of dementia to young children.

## 💻 Tech Stack
This website is a lightweight, fully responsive single-page application built with:
* **HTML5**
* **Tailwind CSS** (via CDN for rapid styling)
* Hosted completely free via **GitHub Pages**
